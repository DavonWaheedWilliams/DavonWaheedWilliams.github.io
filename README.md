# Waheed Davon Williams — Portfolio

A lightweight, responsive personal portfolio built with HTML, CSS, and JavaScript.

## Content

The site includes Waheed's professional profile, research projects, experience, technical expertise, education, résumé, and public contact email. Project source artifacts include two Jupyter notebooks, a database-design presentation, and doctoral research. Home address and phone information are intentionally omitted from the public portfolio.

## Preview

Open `index.html` directly in a browser, or run any static file server in this folder.

## Publish

This folder can be deployed as-is to GitHub Pages, Netlify, Cloudflare Pages, or Vercel. No build command is required; the publish directory is the project root.
